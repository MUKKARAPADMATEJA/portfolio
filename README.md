## 🖥️ How to Run Locally

You can open the website instantly:

1. **Option A (Instant):**
   Double-click `index.html` in your file explorer to open it in your default web browser.

2. **Option B (Python Local Server):**
   Open a terminal in this folder and run:
   ```bash
   python -m http.server 3000
   ```
   Then visit [http://localhost:3000](http://localhost:3000) in your browser.

## 🌐 Free 1-Click Deployment Options

### Option 1: GitHub Pages
1. Create a repository on GitHub named `portfolio` or `<username>.github.io`.
2. Push these files (`index.html`, `style.css`, `script.js`).
3. In repository **Settings > Pages**, set branch to `main` and save.
4. Your site will be live at `https://<username>.github.io/portfolio`!

### Option 2: Vercel
1. Install Vercel CLI: `npm i -g vercel` or go to [vercel.com](https://vercel.com).
2. Run `vercel` inside the `padmateja-portfolio` folder.
3. Your site will be instantly live with a free SSL certificate!
